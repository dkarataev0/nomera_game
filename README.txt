НОМЕРА — КОЛЛЕКЦИОНЕР (PWA)

Как установить на iPhone:
1. Загрузите все файлы из этой папки на HTTPS-хостинг (GitHub Pages, Netlify, Vercel или обычный хостинг с SSL).
2. Откройте адрес игры именно в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Игра появится отдельной иконкой и будет открываться без интерфейса Safari.

Прогресс хранится локально на устройстве. После первого успешного запуска игра кэшируется и может открываться без интернета.

НОВАЯ ВЕРСИЯ ИГРЫ — интерфейс в стиле терминала регистрации автономеров

Что изменено:
- Полностью новый светлый интерфейс поверх игрового фона.
- Левая навигация «Создать новый / Мои номера».
- Раздельная прокрутка цифр и букв.
- Выбор региона.
- Автомобильный / мотоциклетный формат.
- Наличные / карта / коины.
- Редкие и специальные комбинации.
- Оценка номера, репутация, инвентарь и продажа.
- Регистрация транспорта.
- Сохранение прогресса в localStorage.
- PWA/офлайн-режим для iPhone.

Для обновления GitHub Pages:
замените в корне репозитория index.html, manifest.webmanifest, service-worker.js,
icon-192.png, icon-512.png и apple-touch-icon.png файлами из этого архива.

# Номера — коллекционер

Готовая PWA-игра для публикации через GitHub Pages и установки на iPhone как отдельное приложение.

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub, например `nomera-game`.
2. Загрузите **все файлы из этого архива в корень репозитория**.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
6. Через 1–3 минуты GitHub покажет адрес сайта вида:
   `https://ВАШ-ЛОГИН.github.io/nomera-game/`

## Установка на iPhone

1. Откройте опубликованную игру именно в Safari.
2. Нажмите **Поделиться**.
3. Выберите **На экран «Домой»**.
4. Нажмите **Добавить**.

Игра откроется с отдельной иконки и без обычной адресной строки Safari.

## Что уже работает

- адаптация под iPhone;
- плавная прокрутка номерных символов;
- Epic / Legendary / Mythic-анимации;
- гараж с визуальными номерными знаками;
- улучшения и достижения;
- история выпадений;
- локальное сохранение прогресса;
- PWA manifest;
- service worker и офлайн-кэш;
- отдельная иконка приложения.

> Прогресс хранится локально на устройстве в браузерном хранилище. Если очистить данные сайта Safari, локальный прогресс будет удалён.
